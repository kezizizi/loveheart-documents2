# 前端 ↔ 后端契约（实现现状）

> ⚠️ **先读这一节，它覆盖下面所有与之冲突的描述。**
>
> 设计阶段假定过一个 `POST /api/footprint` HTTP 接口，**最终没有采用**。实际承载方式是
> **Streamlit 自定义组件**：`app.py` → `ui/embed.py` 用
> `st.components.v1.declare_component(path="static/web")` 把整个 `static/web/` 交给
> Streamlit 的组件文件服务。前端因此拿到一个**真实 URL**：
>
> ```
> http://<host>/component/ui.embed.ax_footprint/index.html?streamlitUrl=…
> ```
>
> 于是 `style.css` / `app.js` / `assets/**` 的相对路径原样可用，导出（PNG 长图与 CSV）
> 下载也都是原生行为；**不需要**任何构建步骤、npm、或第二个服务器进程。

## 唯一接口：组件消息（不是 HTTP 端点）

| 方向 | 消息 | 载荷 |
| --- | --- | --- |
| 前端 → 宿主 | `streamlit:setComponentValue` | `{ "name": "张三", "sid": "2300017473", "nonce": "…" }` |
| 宿主 → 前端 | `streamlit:render` | `{ "result": {…}, "params": {…} }` |
| 前端 → 宿主 | `streamlit:setFrameHeight` | `{ "height": 1615 }` |
| 前端 → 宿主 | `streamlit:componentReady` | `{ "apiVersion": 1 }` |

* `nonce` 不可省：Streamlit 把组件当控件，值没变就不会重跑；同一个人连查两次
  （点「重新查询」再提交相同姓名学号）会被静默吞掉。
* `params` 是宿主 URL 上的调试开关（`still` / `view` / `open` / `rip` / `degraded` / `name` / `sid`）。
* 高度上报必须 **40ms 去抖 + 高度没变就不发**。否则会形成
  render → 撑高 iframe → 宿主重排 → 再 render 的自激回路（实测 18 秒内 1149 次 render）。

```jsonc
    "name": "张三",

    "joinDateSource": "filled",      // filled = 字段真实值 / created = 回退首次入档 / none
    "companions": 1,                 // 只出人数不出姓名；统计不到是 null（视图显示「—」）
    "joinMessage": "爱心社是一种生活方式",   // 可选；没有就是空串，整块不显示
    "activities": [

        "hours": 2.0, "date": "2025-10-01", "note": "" }

```

**`stats` / `groups` / `terms` / `years` 不在这个载荷里** —— 它们由 `data/derive.js` 在**前端**算，
全站只有那一份实现（后端再算一套就会各算各的，历史上正是这样出现过
「身份栏写着 9 个部组、下面每个活动却都是『其他』」）。
下面「成功」那一节的示例把它们与 `member` 画在同一张图里，请读作
**「前端派生之后的形状」**，而不是后端返回的东西。

翻译层是 `ui/payload.py`：纯函数、不 import streamlit，`tests/test_payload.py` 守着它的格式。
测试可以直接调 `build_payload(result)` 拿到上面这份 JSON。

### 两条格式要求不是风格问题

| 字段 | 前端怎么用 | 写错会怎样 |
| --- | --- | --- |
| `date` | 按**字符串**排序、`new Date(date + 'T00:00:00')` 算天数 | 不补零（`2023-9-1`）会**排序错乱**，时间轴顺序全乱 |
| `term` | 正则 `/^(\d{4})(.*)$/` 取年份、后段判「春/暑」推学年 | 写成 `23秋` 或 `2023-秋` 会让**学年分组整个塌掉** |

## 前端必须遵守的约束

1. **不得突出「志愿学时」。** 学时只是每条记录的一个字段，任何主视图都不得把它求和后放大展示。
   学时求和只允许出现在导出卡片里，作为三个同权重统计格之一，且不排在第一位。
2. **不得请求或渲染敏感字段。** 身份证号、志愿者编号、微信号等由 `config.SENSITIVE_FIELDS`
   定义；前端不把它们写进请求，也不渲染。（后端已有两道断言守着，前端这一侧不要绕过。）
3. **不认识的活动名 / 字段名不要丢。** 后端已处理字段改名与 `SchemaChangedError`；
   前端只渲染约定内的字段，遇到多出来的字段忽略即可，不要报错也不要猜含义。
4. **降级要可见。** 后端在缺 `base:block:read` 时把所有部组判为「其他」，会带上
   `degraded: true`。前端必须给出可见说明（活动本身与参与时间不受影响），不能默默显示。
5. **空记录要解释。** `status: OK` 但 `stats.count === 0` 时，说明活动记录还没和档案建立关联
   （见 `CLAUDE.md` 3.1），这是数据补录问题，不是用户操作错误。

## 前端当前用的是什么

`data/bridge.js` 是全站**唯一**的数据来源抽象，只有两种运行形态：

| 形态 | 何时 | 数据从哪来 |
| --- | --- | --- |
| **组件形态**（生产） | 被 Streamlit 以组件方式挂载（URL 带 `streamlitUrl`，或 iframe 带 `sandbox`） | 组件消息：提交姓名学号 → Python 查飞书 → `args.result` 推回来 |
| **独立形态**（本地设计 / 自检） | 直接用文件或静态服务器打开 `web/index.html` | **动态加载** `data/mock-db.js` 的假数据 |

⚠️ **假数据库只在独立形态下才会被加载。** 生产形态里它连请求都不会发生 ——
原始交接文档里「接口通了、页面却永远显示演示数据」那个坑，是从结构上被排除的，
而不是靠「记得删掉那行 `<script>`」。另有一道保险：只要真收到过组件协议的
`streamlit:render`，就永久锁死演示数据。

`data/derive.js` 负责把「原始记录」算成视图要用的 `stats / groups / terms / years`，
两种形态共用它 —— 这是原始契约里「派生留给前端」那句话的落点。
原始契约把这份派生逻辑放在 `mock-db.js` 里，而 `mock-db.js` 恰恰是接入真实数据时要被
换掉的那一层，所以必须先拆出来。

URL 开关：

| 参数 | 作用 |
| --- | --- |
| `?name=&sid=` | 直接出结果（组件形态下由宿主读取，前端不必自己发查询） |
| `?view=trail\|dossier\|export` | 打开时停在指定视图 |
| `?degraded=1` | 演示部组降级态（**仅独立形态**） |
| `?delay=毫秒` | 调整模拟查询耗时（**仅独立形态**，默认 700） |
| `?still=1` | 关闭全部动效，供截图使用 |
| `?open=N\|all` | 档案视图预展开第 N 个部组 |
| `?rip=solid@600` | 把时间轴涟漪冻结在指定相位 |

组件形态下这些开关挂在**宿主页面**的 URL 上（`document.referrer` 能读到），
因为组件 iframe 自己的 search 里只有 Streamlit 附加的 `streamlitUrl`。

## 自动化自检（156 项，在真实浏览器里跑）

`_work/selftest.html` 用**同源 iframe** 驱动 `web/index.html` 并断言，比 jsdom 更接近真实行为
（同源可直接访问 `contentDocument` 并派发事件）。一键跑法：

```powershell
# 自带静态服务器 + 自选空闲端口 + 一次性浏览器 profile，跑完自动清理
node static/_work/run-selftest.mjs
```

> 别再照抄「`msedge --dump-dom --virtual-time-budget`」那条老命令：`web/index.html` 会在
> 运行时**动态加载** `data/mock-db.js`，虚拟时间预算会在动态脚本到位之前就把页面判定为
> 「没有待办任务」而收工，于是拿到一个还没出结果的页面，报 `EXCEPTION timeout` ——
> 是跑法的假阴性，不是前端坏了。`run-selftest.mjs` 改成等 `#report` 里真的出现 `RESULT` 再收。
>
> 另：自检里「键盘聚焦圆点等价于悬停」这一条，在无头浏览器里需要
> `Emulation.setFocusEmulationEnabled`。不开的话 `el.focus()` 不派发 focus 事件，
> 这条会**在完全未改动的原版前端上同样失败**，也是假阴性。`run-selftest.mjs` 已打开。

- 身份栏四个主指标存在、且**不含「学时」**；
- **硬约束**：足迹与档案视图都不出现学时合计 `107.0`，且面板内没有 ≥26px 的纯数字焦点
  （防止「把总学时放大」的变形回归）；

- 三视图切换、9 个分类夹点击高亮转移；
- 导出卡片 3 个统计格、第三格是「累计学时」、**三格字号一致**（`27px/27px/27px`）；
- **风格统一**：两视图只用中性色 + 一个品牌红（不得出现九色部组配色）、活动名字体与字号一致、
  强调色来自同一个 CSS 变量；

  WAI-ARIA tabs 结构（`role=tablist/tab/tabpanel`、`aria-selected` 唯一、未选中 tab
  不在 Tab 序列里）、加载与提示区有 `aria-live` 播报、样式里定义了键盘焦点规则；
- CSV：BOM 字节 `EF BB BF`、表头、`21 条 + 表头 = 22 行`、首条数据、含感想、不含敏感字段名；
- 四种提示态（三种归因 + 空记录）文案与下一步、降级态（部组数重算为 1）、加载态无假进度；
- **边界数据形状**：单一部组 / 单一学期 / 仅 2 场的社员不塌版（单部组时不显示分类夹索引）；
- **图片资源**：视图内全部 `<img>` 的 `naturalWidth > 0`（路径写错只会显示空白，肉眼易漏）；
- **滑入动效安全性**：单开一个不冻结动效的页面，切到「档案」再切回「足迹」，
  断言此刻视口内的活动记录 `opacity` 均已到 1。

## 时间轴：波动曲线（这一块最容易做错）

时间轴不是一条直线，而是一条**幅度克制的波动曲线**（桌面 ±7px / 波长 430px，窄屏 ±4px / 300px）。
三条硬性要求，缺一就会出问题：

1. **曲线与圆圈必须由同一个函数给出。** 曲线不是「穿过固定圆圈的折线」——那样圆圈必然
   脱离曲线。正确做法是先定义波 `x(y) = cx + A·sin(2πy/λ)`，再用同一个 `x(y)` 去
   `translateX` 每个圆点。校验方式是复算这个函数与已应用的位移比对（当前最大偏差 0.05px）。
2. **学期细线的左端要落在曲线上。** `.term .r` 单元格从 `--gut` 起，而曲线在
   `--gut + --node/2`，所以是 `calc(var(--node)/2 + var(--wave))` —— 漏掉 `--node/2`
   就会恒定偏 17px。
3. **测量时机。** 圆点栏宽 34px（圆点同时是一个 34px 的按钮，触摸目标不能只有 7px），
   圆心 = 单元格中心 = 曲线上的点。但测量必须在面板**可见之后**：`render()` 跑在
   `setView()` 之前，那时面板还是 `hidden`，`scrollHeight` 为 0，量出来全是 0。
   另外两件事也会改变行高，必须重量：**图片加载完**（插画加载前高度为 0，会让它下方
   所有圆点的 y 全部偏小，实测偏差 14px）与**字体加载完**。插画已加 `aspect-ratio` 占位。

### 涟漪与感想展开

| 交互 | 行为 |
| --- | --- |
| 悬停/聚焦**空心**圆点（无感想） | 曲线从该点起产生**轻微**局部波动（幅度 2.6px、衰减 46px、~600ms），不展开任何内容 |
| 悬停/聚焦**红色实心**圆点（有感想） | **更强**波动（4.4px、衰减 78px、~1.1s），同时**中速匀速**展开该场感想 |
| 移出 / 失焦 | 感想收起、曲线恢复 |
| 触摸点击 | 第一次点击展开，再次点击收起，点击别处也收起 |
| 键盘 | `Tab` 聚焦即展开（等价于悬停），失焦收起 |

- 波动是**局部衰减波**，只影响落点附近，不牵动整条曲线。

### 涟漪的确切形状（当前实现）

**空心球与实心球共用同一套算法，差异只在参数。** 这是一条硬性要求，不是风格偏好 ——
中间有一版我给实心球单独做了「驻波式阻尼振荡」，结果整段同向偏移，
看起来就是**一条线像单摆一样左右整体摆**，用户当场指出「没有波浪感」。
教训：**波长 λ 必须显著小于波及范围 maxR**，否则整条受影响区段会同向移动，
退化成单摆；判别式是「同一时刻沿线位移变号几次」（波形 ≥3 次，单摆 0~1 次）。

`X(y,t) = cx + A·sin(2πy/λ) + amp·ring·win·pulse·sin(2πd/λr − t/105)`，其中

- `ring = exp(−(|d| − speed·t)² / 2w²)` —— **环形包络，环半径随时间推进**，
  所以波形是从落点向上下【传播】出去的，不是原地整体起伏；
- `win = (1 − (|d|/maxR)²)³` —— 空间窗口，在 `|d| = maxR` 处**值与一阶导同时归零**，
  所以不会「碰到节点戛然而止」（这是 `q³` 而不是 `q²`：`q²` 时近端与中端只差 11%，
  「随距离渐弱」肉眼看不出来）；
- `pulse = u<1 ? u²(3−2u) : exp(−(u−1)·1.9)`，`u = t/peak` —— **缓入缓出**。
  起手恒为 0 且一阶导为 0，**不会从直线直接跳成波浪线**
  （旧实现用 `exp(−t/τ)`，起手就是最大值，第一帧画出来就是波浪）；
- `sin(2πd/λr − t/105)` —— 行进波。**相位随时间推进**，所以每一个固定高度都会
  随着波瓣经过而来回摆几次（实测 d=60 处变号 3 次），这就是「波浪感」的来源；
- `speed = maxR / (peak·1.6)` —— 环必须在**脉冲仍强**时走完全程。取 `maxR/dur` 会让
  波走到两个节点外时时间脉冲已衰减殆尽，±2 节点处只剩 0.1px：数学上「覆盖到」了，眼睛看不见。

三组参数（实心球 = 振幅更大 · 范围更广 · 时长略长；实测近端 2.65px / ±2 节点 1.23px）：

| kind | amp | w | maxR | λ | 时长 | 用途 |
| --- | --- | --- | --- | --- | --- | --- |
| `hollow` | 2.6 | 47 | 120 | 22 | 1840ms | 空心球（无感想），最克制 |
| `solid` | 4.8 | 88 | 250 | 30 | 2060ms | 红色实心球（有感想），超过左右两个节点 |
| `origin` | 3.2 | 66 | 190 | 26 | 1940ms | 起点黑球，`dir:'down'` 只向下传播 |

`?rip=solid@600` 可把涟漪冻结在指定相位，便于截图看波形（纯展示开关）。
- 圆点是 `<button>`，带 `aria-expanded` / `aria-controls`，键盘与触摸才能对称。
- 感想默认收起，用 `grid-template-rows: 0fr → 1fr` + `linear` 缓动——
  `max-height` 不是匀速，做不到「中速匀速展开」。收起态仍留在无障碍树里，读屏能读到。

## 图片资源与两个踩过的坑

`web/assets/marks/<key>-ink.png`：9 个部组 + 「其他」各一枚线描徽记，单色墨线 + **透明背景**。

生成图直接贴上去有两个问题，转换脚本（`_work/marks-to-ink.py`）一次解决：

1. **底色不等于页面纸色**，直接贴会出现方块边 → 用亮度反推 alpha 去掉底色；
2. **九张风格不齐**（有的纯细线、有的带实心黑块与排线）→ 统一上成同一个墨色。

另外两件事：

- 细抗锯齿线条直接反推 alpha 会**淡成灰雾**，小尺寸下立不住。要加 alpha 增益
  （本实现 `alpha = clip(raw × 1.7, 0, 1) ** 0.8`）。
- **尺寸决定可用性**：同一批徽记在 18–26px 下糊成灰点，等于噪声；36px 以上才读得清。
  所以徽记只用在两处：档案视图的部组头（44px）、足迹终点的「走过哪些部组」一排（36px）。
  足迹起点另有一张宽幅小径插画（`trail-path-ink.png`，同样抠成透明并加了噪点地板）。

## 可访问性

- **对比度**：`--ink-3` 原为 `#8d939a`，对纸色只有 **2.97:1**，用在日期/学时/笔数这类
  信息性小字上不达 WCAG AA。已改为 `#6a7078`（**4.79:1**）。改这个值会影响整页观感，
  但那些小字是信息不是装饰，不能为了通透牺牲可读性。改色请用本文档的公式重量。
- **键盘**：`:focus-visible` 焦点环（鼠标点击不出现）；视图切换是标准 tabs，
  支持 ←/→/Home/End；切换后把焦点交给新面板或结果区，不用键盘用户自己找。
- **读屏**：加载与提示态 `aria-live="polite"`；面板 `role="tabpanel"` + `aria-labelledby`。
- **减少动效**：`prefers-reduced-motion: reduce` 下全部动画关闭。已用
  `--force-prefers-reduced-motion` 渲染并与静止态**逐像素比对，差异 0.0000%**。

## 导出长图（PNG）

**打印 / 存为 PDF 那条路已经删除**（`@media print` 与 `#print` 按钮一并去掉），
导出图改成在浏览器里把卡片拍成 **PNG**。产物是真正的位图文件，可直接发微信。

实现是 `app.js::snapshotCard` + `downloadPng`，管线：

```
克隆 .card → <img> 全部换成 data URI → 取样式表里**非媒体查询**的规则
  → 拼成 SVG（foreignObject）→ new Image() → 画到 canvas → toBlob('image/png')
```

按 2 倍像素出图（540 → 1080 宽），canvas 先铺白底（PNG 透明区在相册里会显示成黑块）。

**四个坑，改这块时别再踩回去**（前两个各花了半小时）：

1. **克隆节点必须用 `XMLSerializer`，不能 `outerHTML`。** SVG 走 `<img>` 加载时按
   **XML** 解析：`outerHTML` 是 HTML 序列化，`<img>` 不会自闭合，XML 解析直接失败，
   症状只有 `img.onerror` —— 除了「快照渲染失败」什么也看不出来。
   `XMLSerializer` 还会顺手补上 `xmlns="http://www.w3.org/1999/xhtml"`，foreignObject 正需要它。
2. **样式文本与内联 `style` 属性都要做 XML 转义。** CSS 里可能有 `<` / `&`；
   而 computed 的 `font-family` 带**双引号**，直接塞进 `style="…"` 会把属性截断。
3. **`@media` 规则必须丢掉。** 渲染成位图时媒体查询按 SVG 自己的宽度求值，
   540px 会命中手机版样式，版式整个变样。
4. **`body` 上的继承属性要显式搬到快照根节点。** `<style>` 是按 SVG 文档生效的，
   那里没有 `body`，卡片就继承不到字体与文字颜色（会变成 Times 黑字）。

另外：动画要钉死在终态（克隆节点加 `.snapping`），否则快照可能赶在 `anim-rise`
（opacity 从 0 起）中途，拍到一张半透明的卡。

验证靠 `_work/e2e-streamlit.mjs`：它把 Blob **读出来**验 MIME、PNG 魔数
（`\x89PNG\r\n\x1a\n`）、能被 `new Image()` 解码出正尺寸、文件名以 `.png` 结尾，
并把这张 PNG 落盘到 `_work/e2e-shots/export-card.png` 供人眼复核。
